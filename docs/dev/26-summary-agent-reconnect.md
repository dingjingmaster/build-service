# 26 Agent 断线重连总结

- 日期：2026-10-21；级别 L3；本地上下文。
- 仅修改 src/agent.rs 及相关总文档/本地任务文档，server 实现、配置和 JSON 协议未修改。

## 实现与结果

- 连接建立（含握手）、等待 HelloAccepted、每次发送分别限制 10 秒。
- 注册后立即探活，正常每 5 秒发送标准 Ping；等待匹配载荷 Pong 最多 15 秒。探活走独立控制通道，优先于业务发送队列；reader 仅确认当前探测的 Pong，无关或过期 Pong 不覆盖确认。业务命令串行处理与网络读取分离，等待并发名额不阻塞 Pong。
- 读、写、探活、串行业务处理在同一连接作用域并行；任一路退出或失败都取消其它连接 future，结束心跳并等待其退出，释放 socket，关闭终端并向已有任务发送取消信号。
- 已注册连接断开立即再次尝试；连接/注册失败每 3 秒重试，无次数上限。保留持久化身份。
- 不实现任务续跑，不改变已有下载/升级任务生命周期或构建进程终止方式。

## 验证

- 本地 Linux x86_64，rustc 1.98.1。
- 修复前：3 个回归用例按预期失败（22 秒）；E3 证明相应实现缺口，未宣称复现部署环境唯一根因。
- 修复后：`env NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost cargo test` 全量 40 passed，0 failed（18.07 秒）；显式让本地 HTTP 下载测试绕过宿主环境代理。
- 新增 9 个连接测试：WebSocket 握手无响应、Hello 无响应、Pong 无响应、正常 Close 后立即重连、启动离线与三轮端口关闭/恢复（同一 agent、相同身份）、非法消息后释放旧 socket、使用 axum 自动 Pong 的健康空闲连接、等待任务并发名额时持续探活、匹配 Pong 后紧接无关 Pong 不丢确认。
- cargo check、cargo fmt --check、git diff --check 通过。
- 一次受沙箱限制的测试在 bind 阶段报 EPERM；按要求在授权的沙箱外重跑成功，属于环境限制。
- 未做生产部署、真实网络设备拔线、写入阻塞压力测试、Windows/macOS 实测；现有取消策略不保证任务续跑，也不保证下载阶段立即停止。15 秒探活超时意味着长时间系统暂停或运行时整体饥饿也可能触发重连。

## 1. 修改目标

- 原始需求：server 界面的 Builds 模块高度与 Agents 模块一致，均显示 8 行，超出后添加滚动条。
- 成功标准：Builds 与 Agents 表格容器使用相同固定高度，表头下可显示 8 条数据，更多数据在容器内纵向滚动。

## 2. 修改结果

- 修改文件：`src/server/ui.rs`
- 行为变化：新增 Builds 表格滚动类，并与 Agents 共用 `342px` 最大高度；Builds 和 Agents 超出可视范围后在表格内滚动。
- 不适用项：未修改 API、数据结构、依赖或总产品/开发文档。
- 安全门禁执行结果：仅工作区内局部 CSS/HTML 修改，未执行破坏性操作。

- 涉及命令权限级别：C0 只读检查、C1 工作区内修改和验证。
- 是否覆盖用户已有修改：否。

## 1. 修改目标

- 原始需求：Agent 设置禁止远程控制关机时，服务端 Agents 列表中的关闭按钮不可点击；该 Agent 置顶并使用淡金色背景。
- 成功标准：`shutdown_enabled=false` 的 Agent 排在 Agents 列表顶部、行背景为淡金色、关闭按钮为禁用状态；允许关机的 Agent 保持原有行为。

## 2. 修改结果

- 修改文件：`src/server/ui.rs`。
- 行为变化：Agents 列表排序优先将禁止远程关机的 Agent 置顶；对应行增加淡金色背景；关闭按钮继续并明确保持禁用，并显示禁止原因提示。
- 不适用项：未修改 server API、agent 配置、协议和真实关机流程。
- 安全门禁执行结果：仅进行工作区内局部 UI 修改，未执行破坏性操作。
- 风险矩阵结论：单模块、低风险用户界面行为调整，按 L1 处理。
- 涉及命令权限级别：C0 只读检查、C1 工作区内补丁和定向验证。
- 是否覆盖用户已有修改：否；`Cargo.lock` 的已有版本变更未触碰。

## 3. 验证

- 验证环境：本地 Linux 工作区。
- 命令/步骤：`cargo fmt --check`；`cargo test`；`git diff --check`；人工检查 Agents 渲染逻辑。
- 结果：通过。
- 未执行验证项：未进行浏览器像素级检查。
- 未覆盖风险：不同浏览器下淡金色显示及实际点击事件的端到端表现未覆盖。

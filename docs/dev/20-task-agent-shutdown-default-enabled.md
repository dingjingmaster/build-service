# Agent 远程关机默认允许

> 文档元数据
> - 文件编号：20
> - 文档类型：task
> - 文档版本：v1.0.0
> - 最后更新：2026-08-04
> - 需求级别：L2
> - 关联需求：默认允许 Agent 远程关机，配置明确为 false 时禁止

## 1. 目标

- 要解决的问题：当前未配置 `shutdown_enabled` 时默认禁止远程关机，与新的产品策略不符。
- 成功标准：配置缺省和旧 Hello 消息均按允许处理；显式 `shutdown_enabled = false` 时 UI、server API 和 agent 本地仍禁止关机。

## 2. 背景与边界

- 背景：现有 Agent 关机权限链路已覆盖配置、Hello、UI、server API 和 agent 本地执行检查。
- 包含：调整配置解析默认值、旧协议字段缺省值、示例配置、测试和当前产品文档。
- 不包含：修改 server API、关机命令、UI 禁用/置顶样式或数据库结构。
- 关键假设：缺少 `shutdown_enabled` 的旧 Agent 配置视为未明确禁止，因此允许关机。
- 非目标：不执行真实关机测试。
- 最大修改范围：Agent 配置/协议默认值、示例和相关文档。
- 禁止触碰范围：不覆盖用户已有工作区修改，不修改 `AGENTS.project.md`。

## 4. 方案

- 推荐方案：配置解析使用 `true` 作为缺省值，协议 Hello 缺少字段时也使用 `true`，显式 false 继续沿用现有三层拒绝链路。
- 取舍理由：满足“仅明确禁止才拒绝”的策略，同时兼容未携带新字段的旧 Agent。
- 风险与应对：默认开启远程关机扩大系统副作用范围；文档和示例明确提供 `shutdown_enabled = false` 的禁用方式。
